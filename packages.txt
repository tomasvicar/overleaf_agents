# TeX Live packages installed on top of scheme-basic.
#
# Keep this list as small as it can be while still compiling real manuscripts.
# Blank lines and #-comments are ignored. A comment must be on its own line --
# every other line is passed to tlmgr verbatim.
#
# If a paper needs something that is not here:
#   1. add it below, open a PR -> CI rebuilds and pushes a new image, or
#   2. install it at runtime into a persistent texmf volume (see README).

# --- build driver -----------------------------------------------------------
latexmk

# --- the standard LaTeX stack ------------------------------------------------
collection-latexrecommended
collection-fontsrecommended

# --- bibliography ------------------------------------------------------------
biber
biblatex
natbib
bibtex
apacite

# --- maths and units ---------------------------------------------------------
amsmath
mathtools
siunitx
physics
# upgreek.sty ships in `was`. bm.sty, subcaption.sty, rotating.sty and
# mathptmx.sty are not package names of their own -- they arrive with tools,
# caption, graphics and psnfss respectively, so they are not listed here.
was
cancel
esint
# esint ships its fonts as METAFONT sources only, and the image deletes
# fonts/source -- without the Type1 companion, \oiint fails at the font stage
esint-type1
stmaryrd
braket
nicematrix
thmtools
optidef
mhchem
# doublestroke provides dsfont.sty (\mathds)
doublestroke

glossaries

# libertine and inconsolata are acmart's body and mono fonts. Without them
# acmart only warns and falls back, so the paper still compiles but paginates
# differently from Overleaf -- which matters when there is a page limit.
libertine
inconsolata

# --- journal document classes ------------------------------------------------
revtex

# acmart loads these but does not declare them as dependencies

llncs
# Not here on purpose: siamltex and copernicus are not in TeX Live at all --
# SIAM and Copernicus ship their class with the template, so the file arrives
# in the project itself and compiles without anything being installed.

# --- languages ---------------------------------------------------------------
# babel-czech/-slovak and their hyphenation patterns. Other languages come in
# the same shape -- collection-langgerman, collection-langfrench, and so on,
# 1-3 MB each -- so add the ones your group actually writes in.
collection-langczechslovak

# --- graphics helpers --------------------------------------------------------
pgf
pgfplots
standalone

epstopdf-pkg
circuitikz

# eepic provides epic.sty, which overpic requires and does not declare
eepic
# \includesvg additionally needs Inkscape, which is not in the image. The
# package is here so that a document merely loading it still compiles.
svg

# --- tools the review workflow uses ------------------------------------------
# latexdiff produces the marked-up PDF that stands in for Overleaf's track
# changes; texcount checks a journal's word limit; chktex lints.
latexdiff
texcount
chktex
